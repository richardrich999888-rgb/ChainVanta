# Security

ChainVanta 0.1 is a local engineering prototype. Do not deploy it for production customers or treat it as a cryptographic security attestation. See [security architecture](docs/architecture/security-architecture.md) for trust boundaries and outstanding controls.

Do not post secrets, customer data or working exploit details in public issues. If GitHub private vulnerability reporting is enabled, use the repository's Security → Report a vulnerability flow. Otherwise contact the repository owner through an already established private channel; no private reporting address has been configured in this repository.

Include affected revision, reproduction steps, impact, expected behavior and proposed remediation where available. Do not test on third-party accounts or infrastructure without authorization. No response-time SLA is established yet.
